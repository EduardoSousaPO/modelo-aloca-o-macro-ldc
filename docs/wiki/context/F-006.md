## 3. Como a fonte funciona (o essencial para mexer no módulo)

```
GET .../indexStatisticsProxy/IndexCall/GetPortfolioDay/{base64(json)}
payload = {"language":"pt-br","index":"IBOV","year":"2006"}   # year é STRING, sem espaços
headers = User-Agent de browser + Referer: https://sistemaswebb3-listados.b3.com.br/
```

- resposta = `{"min":…,"max":…,"results":[31 itens]}`; cada item tem `day` (1..31) e
  `rateValue1..12` = jan..dez → **matriz dia × mês**, precisa de *unpivot*;
- valores são **string pt-BR** (`"38.484,84"`) → só `para_float_ptbr` (CA-035);
- só fechamento, **sem OHLC**; feriado/dia inexistente vem `null` → **linha omitida**, nunca `0`
  (CA-037). Por isso `% nulos = 0,00` nas 11 séries: o parquet só tem dias com fechamento;
- **ano sem série é HTTP 200 com `{"min":null,"max":null,"results":null}`** — ausência legítima, não
  erro. Já um **código inexistente (`XXXX`) devolve esse mesmo corpo**: o corpo não distingue. Quem
  distingue são (a) a validação do código contra o catálogo antes da requisição e (b) a guarda de
  contagem mínima baseada no `data_inicio` do catálogo;
- **erro de verdade** vem como HTTP 200 com **corpo de 0 byte** (payload base64 inválido) ou HTML
  (a SPA). Os dois são recusados com `RespostaDeErroComStatus200`.

## 4. Decisões tomadas aqui

1. **O universo sai do catálogo, não de lista literal.** `indices_do_catalogo()` filtra
   `fonte = B3_API` + `status = ok` + código de 4 letras — `IFIL` e `B3_COTAHIST` (ambos
   `descartada`) caem fora sozinhos e voltam sozinhos se a decisão mudar.
2. **A guarda anti-truncamento é o `data_inicio` do catálogo** (`pontos_minimos_do_ano`): ano antes
   do início → 0 esperado; ano do início → 1 (ponto-base); ano completo → 240; ano corrente →
   15 × meses fechados. É o que faz "ICON/2006 = 1 ponto" ser aceito e "IFIX/2012 vazio" levantar.
3. **Célula vazia é linha omitida** (a outra opção de CA-037, `NULL`, exigiria carregar o calendário
   de bolsa — que é F-008 e ainda não existe).
4. **`collected_at` vem do manifesto do bruto**, não do relógio da rodada. É o que torna a segunda
   execução byte-idêntica (verificado: mesmos sha256 dos 11 parquets).
5. **`vintage` nulo**: fechamento de índice da B3 não é revisado (diferente do PIB do IBGE).
6. **Nome do bruto é `<ano>.json`**, não o `<id>__<AAAA-MM-DD>` de `nome_arquivo_raw`: o arquivo é a
   matriz de um ano inteiro, então a referência é o ano, e o índice já é o diretório.

## 5. O que F-006 **não** faz

- **retorno total índice a índice** — gap **G-01** aberto: `is_total_return` é `True` só para IBOV e

- `IFIL`/IFIX-L (liquidez, não segmento), COTAHIST (fase 2), FII por segmento (**F-012**, Teva);
- qualquer agregação trimestral, retorno ou alinhamento — é **F-017** (e trimestral primário é
  proibido, Anti-SPEC §10.4.28);
- política de cache condicional por fonte (**F-030**) — cada rodada ao vivo refaz as 231 requisições.
