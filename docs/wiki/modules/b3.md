# Módulo `b3` — Índices B3 (ações, setoriais, FII) + Teva

> Síntese — fonte de verdade: `docs/research/fontes-de-dados.md §B8-B9`. **Status: nenhum extrator implementado** (2026-10-10).

## Propósito

Extrair os índices de bolsa que formam o lado "ativos" do heatmap: amplos, setoriais e IFIX, pela API
interna da B3 (`apps/pipeline/extract/b3_indices.py`), mais o **FII por segmento** via **Teva**
(`teva.py`), que entra aqui porque a B3 **não tem** índice setorial de FII.

## Fonte primária e fallback

- **Primária:** `GET .../indexStatisticsProxy/IndexCall/GetPortfolioDay/{payload_b64}`, payload base64 de `{"language":"pt-br","index":"IBOV","year":"2006"}`, com **UA de browser + `Referer` da B3**. Teva: bucket GCS público `teva-indices-public`.
- **Fallback:** Yahoo `^BVSP` (1993+) só para IBOV; ETFs (`BOVA11` 2008, `XFIX11` 2020 — **price return**, subestimam total return); COTAHIST + CVM para construção própria de FII (esforço alto, F-038).

## Armadilhas conhecidas (pesquisa)

- **Resposta é matriz dia × mês:** `results` tem 31 itens (`day` 1..31) e `rateValue1..12` = jan..dez → precisa de *unpivot*. Valores são **strings pt-BR** (`"38.484,84"`), só fechamento, sem OHLC; feriados vêm nulos (R13).
- **R9 · as páginas da B3 são shells Angular** (~2,3 KB, só `<app-root>`) → scraping de HTML **não funciona**; o caminho é a API. Playwright só para diagnóstico, nunca no pipeline.
- **Yahoo é armadilha para setoriais:** `SMLL.SA`, `IFIX.SA`, `IMOB.SA` etc. respondem **HTTP 200 com 1 único ponto** em qualquer `range`; `^IFIX`/`^SMLL` dão 404. Validar sempre `len(df) > 1`. O Yahoo também **troca a granularidade em silêncio** (`1mo` → `1wk`) → pedir `interval=1d` e reamostrar.
- **R14 · códigos:** energia é **`IEEX`** (não `IEE`) e IFIX-L é **`IFIL`** (não `IFIXL`). `GetIndexStatistics`, `GetPortfolioYear` e similares **não existem** (404).
- **R7/R20 · Teva:** nome do arquivo tem **versão embutida** (`v0.27`) → listar o bucket e casar por regex; é **provedor privado sem licença comercial explícita** (decisão **L2**) e cobre só ~2 ciclos macro → uso **qualitativo**.
